A default 1-3 MST: 12 routing items, easy/medium/hard modules of 24

## Usage

``` r
ty_mst_default(center = 0)
```

## Arguments

- center:

  Center of the difficulty range.

## Value

A \`ty_mst\`.

## Examples

``` r
ty_mst_default()$cuts
#> [1] -0.55  0.55
```
